# 🔗 Supply Chain Management (SCM)

Este é um sistema de gerenciamento da cadeia de suprimentos (SCM) desenvolvido com **Streamlit**.  
Ele permite gerenciar **fornecedores**, **produtos**, **movimentações de estoque** e **pedidos de compra**, além de fornecer uma **visão geral do estoque**.

---

## 🚀 Funcionalidades

### 📦 Fornecedores
- Cadastro de fornecedores com:
  - Nome
  - Contato (email, telefone, etc.)
- Exibição da lista de fornecedores cadastrados

### 📋 Produtos
- Cadastro de produtos com:
  - Nome
  - Categoria
- Exibição da lista de produtos cadastrados

### 📊 Movimentação de Estoque
- Registro de **entradas** e **saídas** de produtos no estoque
- Histórico detalhado de movimentações com:
  - Data e hora
  - Tipo de movimentação (Entrada ou Saída)
  - Quantidade movimentada

### 📑 Pedidos de Compra
- Criação de pedidos de compra com:
  - Produto
  - Fornecedor
  - Quantidade
- Exibição da lista de pedidos com status e detalhes

### 📈 Visão Geral de Estoque
- Exibição do **saldo total** de cada produto no estoque

---

## 🛠️ Tecnologias Utilizadas

- **Python**
- **Streamlit** – Interface interativa e visual
- **Datetime** – Registro de data e hora das movimentações
- **UUID** – Geração de identificadores únicos
